# data.yappman.com

The website of Yappman Data, a trading name of Abley-Yapp Consulting Limited: weekly price indices and notes on the data behind them.

- Site: https://data.yappman.com/
- The published index data is licensed CC BY 4.0. Please credit Yappman Data and say if you changed anything: https://creativecommons.org/licenses/by/4.0/
- The indices measure posted online shelf prices. They are not a consumer prices index.
- Contact: info@yappman.com

This repository is public. It holds the pages of the site and the scripts used to publish it.
