Notice: default retailers change

UK Supermarket Price Scraper on the Apify Store. Posted 8 October 2026. Ships no earlier than 9 November 2026.

Updated 27 October 2026: the release date moved from no earlier than 7 November to no earlier than 9 November 2026, in a separate build after the matchKey change.

Announced change to the default retailers (UK Supermarket Price Scraper), 8 October 2026. Ships no earlier than 9 November 2026, in a later build than the matchKey change. Morrisons stays opt-in until then. A run that does not set retailers will search all five retailers (Tesco, Sainsbury's, Asda, Aldi and Morrisons) instead of Aldi and Sainsbury's. maxItems is shared equally between the shops that run, so a default call (100 items) returns up to 20 rows from each of five shops instead of up to 50 from each of two. It is still at most 100 rows, so what it costs is unchanged ($0.255 on the Free plan: $0.005 to start and $0.0025 for each of up to 100 products). A run with maxItems set to 0 (no limit) is different: it returns, and charges for, rows from all five shops instead of two. To keep today's behaviour, set retailers to ["aldi", "sainsburys"]; runs that name their retailers are not affected. UK edition only; no field, price or event changes.
