Free sample: FSA approved food establishments, England and Wales (first 1,000 approvals)

The first 1,000 approvals by approval number in the Food Standards Agency’s daily file of 20 November 2026, read on 22 November 2026.

Some links to Apify are affiliate links: if you sign up through them we may earn a commission.

Download the CSV (999 rows, about 167 KB)

SHA-256 of the CSV: b2cc945fbc33ddcf7140949f773fb17a30091edbd590876e05d0489639ed8b63.

What the sample is

  • The first 1,000 approved establishments in England and Wales by approval number, in the order the Actor returns them, from the FSA daily file of 20 November 2026. One row was removed by a rule that drops names that look like an individual’s, so the file has 999 rows. The rule is cautious and can remove an organisation.
  • It is not a random sample and it is not representative of the whole list: 217 local authorities appear, but unevenly (Birmingham 76 rows, Cornwall 53).
  • Postcode district only (for example B66): no street address, no town, no operator or contact names, no telephone numbers.
  • Source file: https://fsaopendata.blob.core.windows.net/fsaopendatacatalog/source_data.ApprovedEstPublication_Daily.csv (the FSA’s daily file). The data.gov.uk catalogue lists monthly snapshots of the same list.

Columns

ColumnMeaning
approvalNumberThe FSA approval number as published (the numeric part; the FSA's key is "ew:" plus this number for England and Wales).
tradingNameThe establishment's name as the FSA publishes it. Operators whose name looks like an individual's were removed (1 row of 1,000).
areaengland-wales: the FSA file's area for the row.
postcodeDistrictThe postcode district only (for example B66), never a full postcode or address.
localAuthorityThe local authority name as the FSA publishes it.
competentAuthorityThe competent authority named in the file (for example the Food Standards Agency itself, or a local authority).
activityCodesSpace-separated activity and section codes as published (for example A0, A5, T:cutting_plant): approval sections, species and activity types. See the FSA's own list for their meaning.
observedAtThe date of the FSA daily file the row was read from (2026-11-20).

Maintained version

The Apify Actor FSA Approved Food Establishments: England, Wales, NI returns the FSA’s approved establishments list on demand, priced pay per event.
