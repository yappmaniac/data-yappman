UK Online Shelf-Price Index: data dictionary

The fields of the public dataset uk-shelf-price-index. How the figures are computed is on the method page.

Download

The whole series in one file, every vintage: CSV or JSON (dataset id AvRCWqFinCiNjx3sP, readable by anyone with the id). Licensed CC BY 4.0. The data is in long format: one row per vintage, record type, retailer and class.

Row fields

FieldTypeMeaning
vintagetextThe ISO week the row describes, e.g. 2026-W42. One vintage per week. Published index values are not revised except to correct an error.
publishedAttextWhen the vintage was published (UTC timestamp).
revisionnumber1 for every row so far. A correction would be a new, clearly marked revision.
recordTypetextWhat the row aggregates; see the record types below.
retailertextRetailer id, or empty for an all-retailer row.
classtextClass id, or empty for a row over all classes.
levelnumberIndex level; the base week is 100.
weekOnWeekPctnumber or emptyChange on the previous week, in percent.
fourWeekPctnumber or emptyThis week's level against the level four weeks earlier, in percent. Empty wherever that earlier level is missing.
matchednumber or emptyProducts matched in both weeks and used. Empty in the base week.
matchedSharenumber or emptyMatched products as a share of last week's products (0 to 1). Empty in the base week.
statustextok; carried (fewer than 20 used products, so last week's level is kept); insufficient (no used products, level kept); base (the base week).

Record types

  • headline: all four retailers, all classes.
  • retailer: one retailer over all its matched products.
  • class and retailer_class: a class across retailers, and a retailer within a class.
  • subtotal and retailer_subtotal: food and soft drinks, the ten classes from bread-cereals to soft-drinks together. Not one of the 16 classes. In 2026-W39 and 2026-W40 this figure was published as class and retailer_class rows named food-soft-drinks.
  • meta: one per vintage; see below.

Values

  • Retailers: tesco, sainsburys, asda, aldi.
  • Classes (16): bread-cereals, meat, fish, dairy-eggs, oils-fats, fruit, vegetables, sugar-confectionery, food-other, soft-drinks, alcohol, household, personal-care, baby, pet, other.

Meta item

Each vintage has one item with recordType meta, with these fields besides vintage, publishedAt and revision:

FieldMeaning
titleUK Online Shelf-Price Index
baseThe ISO week at which this vintage's series equals 100 (2026-W39 or 2026-W42).
weighting"equal retailer weights; equal product weights within a cell"
retailersThe retailers in the vintage.
classesThe classes in the vintage.
matchedTotalMatched products across the retailers. Empty in the base week.
coverageWarningsRetailers whose snapshot covered far fewer products than the week before.
headlineRetailersNumber of retailers in the headline: 4 in every published UK week (a week is not published otherwise); empty in the base week.
methodologyUrlThe method page.
notCpiAlways true: this is not a consumer prices index.
measures"posted online shelf prices at the named retailers, not prices paid"
licenseCC BY 4.0
subtotalsThe subtotal published with the vintage (food-soft-drinks).

Only aggregates are published: no product names, ids, URLs or prices.
