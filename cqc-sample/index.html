Free sample: CQC registered care locations in England (53 locations)

53 registered locations from CQC’s published directory file of 28 October 2026, read on 23 November 2026.

Some links to Apify are affiliate links: if you sign up through them we may earn a commission.

Download the CSV (53 rows, about 7 KB)

SHA-256 of the CSV: c10ec6853413408b24ee73fd46c1ac0d7e84136545f47e728a329f7d093b58b0.

What the sample is

  • The first 55 registered locations in the order the Actor returns them (by location id), from its stored copy of CQC’s directory file of 28 October 2026. Two were removed because their names name a person, so the file has 53 rows. The check is rule-based and can be wrong.
  • It is not a random sample and it is not representative: 37 of the 55 read were homecare agencies, and 18 were in London.
  • No ratings and no registration dates: the directory file the Actor reads does not carry them, so the sample cannot say anything about ratings.
  • Postcode district only (for example SW1A), never a full postcode. No provider name, manager or nominated individual, address, telephone number or bed numbers.
  • The exact CQC file name and page were not confirmed with CQC for this sample.
  • A change in this data means CQC’s published data changed, not that care changed.
  • Source: the Care Quality Commission’s published care directory file (file date 28 October 2026), as held by the Actor.

Columns

ColumnMeaning
locationIdThe CQC location id as published (for example 1-10005907441).
locationNameThe location's name as published. Rows whose name looks like it names a person were removed (rule-based; can be wrong).
providerIdThe CQC provider id. The provider name is not in the Actor's output, so it is not in the sample.
locationTypeThe CQC service type(s) of the location, separated by "; " (for example Homecare agencies).
regionThe CQC region as published.
localAuthorityThe local authority as published.
postcodeDistrictThe postcode district only (outcode), as the Actor outputs it; never a full postcode.
registrationStatusRegistered for every row (the directory lists registered locations only).
observedAtWhen the Actor's stored copy of the directory file was taken (2026-11-01T21:07:41Z).

Maintained version

The Apify Actor CQC England care locations searches and looks up care locations in CQC’s directory on demand, priced pay per event.
