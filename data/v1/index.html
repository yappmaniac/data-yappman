Free index files: stable addresses

The UK and AU Online Shelf-Price Index as CSV and JSON at addresses that keep their meaning. Weekly series, not real time. Licensed CC BY 4.0.

The files

IndexCSVJSONPage
UK Online Shelf-Price Indexuk-shelf-price-index.csvuk-shelf-price-index.jsonindex, data dictionary
AU Online Shelf-Price Indexau-shelf-price-index.csvau-shelf-price-index.jsonindex, data dictionary

manifest.json lists, for each index, the latest week and the day it was published, the number of rows, and the size and SHA-256 of each file, so you can check a download. Each week’s figures are added to the files when they are published; published values are not revised except to correct an error, and a correction is a new, marked revision. Browsers and proxies may keep a copy of a file for a few minutes.

What is in a file

Long format: one row per week, record type, retailer and class. The JSON holds the same figures as the public dataset, with the meta item first for each week. The CSV holds the rows without the meta items and one extra last column, base: the base week of that week’s series. For the AU CSV, empty means no value and numbers are written as in the JSON. What each column and record type means is in the data dictionaries linked above.

Versioning

Within v1 a column keeps its meaning and its place; new columns are added at the end. A change that would break a reader is announced on the notices page before it ships, and a new path will normally be used for it. The older addresses under /data/ hold the same files and are intended to keep working; if one is ever withdrawn, that is announced on the notices page first.

Changelog

The changes below are from the method pages, which give the full text: UK and AU.

  • UK, 5 October 2026: first week published, 2026-W40, with the 2026-W39 base rows.
  • UK, after 2026-W40: the combined “food and soft drinks” figure is published as a subtotal (record types subtotal and retailer_subtotal); weeks 39 and 40 stay as published.
  • UK, 12 October 2026: week 41 skipped; the index restarted with a new base at 2026-W42 (notice).
  • UK, 26 October 2026: the new series published (2026-W42 base rows and the 2026-W43 figures); from this week a pack size missing in one of the two weeks is treated as unknown and the shelf price is compared.
  • UK, from 2026-W44: a product relaunched under a new identifier with the same barcode is matched within its retailer, and the columns entered, left, relinked and missingPackSize are filled for headline and retailer rows; the published 2026-W43 figures are unchanged.
  • AU, 15 October 2026: first weeks published, the 2026-W41 base and 2026-W42.

Copy-and-paste recipes

Each reads the UK CSV; change the address for the AU file. They keep the headline rows, one per week. The UK index has two series, with base 2026-W39 (weeks 39 and 40) and base 2026-W42 (from week 42), which are not joined: keep the base column with the level, and do not chart levels from different bases as one line.

Python

import pandas as pd
df = pd.read_csv("https://data.yappman.com/data/v1/uk-shelf-price-index.csv")
headline = df[df["recordType"] == "headline"]
print(headline[["vintage", "base", "level", "weekOnWeekPct"]])

R

df <- read.csv("https://data.yappman.com/data/v1/uk-shelf-price-index.csv")
headline <- subset(df, recordType == "headline")
head(headline[, c("vintage", "base", "level", "weekOnWeekPct")])
